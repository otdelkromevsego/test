# Проект test

## Описание

Репозиторий предназначен для хранения и анализа рабочих файлов проекта.

## Структура проекта

В репозитории будут размещаться:

- Excel-файлы отчетов и моделей;
- документы с описанием процессов;
- вспомогательные файлы автоматизации;
- результаты анализа данных.

## Правила работы с файлами

- Файлы VBA с расширением `.bas` могут храниться отдельно и анализироваться выборочно.
- При анализе проекта учитываются все остальные типы файлов.
- Для каждого крупного изменения рекомендуется создавать отдельный commit.

## Цель проекта

Создание единой структуры хранения, анализа и развития рабочих инструментов.

# Архитектура модели WB Price Optimizer

## Общая схема

1. Загрузка исходных отчетов WB.
2. Обработка данных.
3. Расчет экономических параметров.
4. Анализ спроса.
5. Расчет рекомендуемой цены.
6. Контроль результата.

## Блоки системы

### Блок данных

Источники:
- отчеты продаж;
- остатки;
- воронка продаж;
- себестоимость.

### Расчетный блок

Параметры:
- цена;
- комиссия;
- логистика;
- прибыль;
- эластичность спроса.

### Аналитический блок

Контроль:
- продажи;
- конверсия;
- остатки;
- оборачиваемость.

## Развитие

В дальнейшем модель может быть расширена автоматическим обновлением данных и прогнозированием спроса.

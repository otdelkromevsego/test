# Анализ проекта WB Price Optimizer

## 1. Назначение проекта

Проект предназначен для разработки системы анализа и оптимизации цен товаров на маркетплейсе Wildberries.

Основные задачи:

- расчет оптимальной цены товара;
- анализ продаж;
- учет остатков;
- учет себестоимости и логистики;
- оценка влияния изменения цены на спрос;
- подготовка управленческих решений.

## 2. Источники данных

В проект входят следующие группы данных:

- отчеты Wildberries;
- история остатков;
- воронка продаж;
- себестоимость продукции;
- расчетная модель цены.

## 3. Архитектура проекта

Общий поток данных:

Источник данных → обработка → расчет параметров → оптимальная цена → управленческое решение

## 4. Основные направления анализа

- экономика товара;
- маржинальность;
- эластичность спроса;
- сезонность;
- влияние остатков на цену;
- скорость продаж.

## 5. План развития

Версия 1.0:

- стабильная загрузка отчетов;
- корректное обновление данных;
- исправление ошибок в расчетах.

Версия 2.0:

- прогнозирование спроса;
- автоматическая корректировка цены;
- расширенная аналитика.
